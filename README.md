# Supreethraj_Task15

## Project Overview
This project is a simple JavaScript file that works with an array of numbers. It finds the biggest number, adds all the numbers together, and counts how many even numbers are in the array. The code is in `js/functions.js` and it uses loops and functions.

## Learning Objectives
* Understand how to use a normal function to find the maximum number in an array.
* Write a anonymous function that adds all array values to get the total sum.
* Use an arrow function to count even numbers in the array.

## How to Run
1. Open the folder on your computer.
2. Make sure `js/functions.js` exists in the `js` folder.
3. Open a terminal in the project folder.
4. Run `node js/functions.js` to see the output in the console.

## Reflection & Key Takeaways
I learned how to compare numbers one by one to find the largest value. The `maximum` function starts with the first number and updates the biggest number when a larger one appears.

I also learned that adding numbers in a loop is easy with a running total. The `summation` function adds each element and returns the final sum.

Finally, the arrow function `NoOfOdd` shows how to count even numbers using `% 2` and `if`. It was fun to see the results print in the console.
